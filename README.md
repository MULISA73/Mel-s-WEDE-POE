# 1. Project Overview

Mel's Cakes & Treats is a business website developed to showcase baked products and provide customers with an online platform where they can explore products, learn about the business, request quotations and make enquiries.

The website was developed in three stages (Part 1, Part 2 and Part 3). Each stage focused on improving the website's structure, appearance, responsiveness, functionality and overall user experience.

The project uses HTML5 to structure the pages, CSS3 to control the appearance and layout, and JavaScript to introduce interactive features.

The website follows a burgundy, pink and white colour scheme to create a consistent bakery-themed appearance.

# 2. Project Objectives

The main objectives of the project are to:

- Develop a professional website for Mel's Cakes & Treats.
- Showcase the products and services offered by the business.
- Provide customers with information about the business.
- Allow customers to submit product enquiries and quotation requests.
- Create a responsive website that works on desktop and mobile devices.
- Improve website functionality through JavaScript.
- Improve search engine optimisation (SEO).
- Provide a user-friendly and visually appealing experience.

# 4. Website Structure

The website consists of five main pages.

### 4.1 Home Page – INDEX.html

The home page introduces Mel's Cakes & Treats and provides visitors with an overview of the business.

### 4.2 About Us Page – About.html

The About Us page provides information about the business, its background, mission, vision and frequently asked questions.

### 4.3 Products Page – Products.html

The Products page showcases the available products, including:

- Custom cakes.
- Wedding cakes.
- Cupcakes.
- Cookies.
- Dessert boxes.

### 4.4 Enquiry Page – Enquiry.html

The Enquiry page allows customers to request quotations and provide information about their preferred products, event dates, flavours and additional requirements.

### 4.5 Contact Page – Contact.html

The Contact page provides customers with the business's contact information and communication options.

## 5.3 Part 3 – Functionality, Interactivity and SEO Enhancements

Part 3 focused on improving the functionality of the existing website through JavaScript, responsive navigation, form validation, AJAX and search engine optimisation.

The existing website design was maintained while additional features were introduced.

### 5.3.1 Product Search and Category Filtering

JavaScript was added to the Products page to allow customers to search for products and filter products according to their categories.

Customers can:

- Search for products by entering keywords.
- Filter products by category.
- View the matching products.
- Receive feedback when no matching products are available.

The functionality was implemented in `js/products.js`.

### 5.3.2 Interactive Image Gallery and Lightbox

An interactive image gallery was introduced to improve how customers view product photographs.

Customers can click on product images to display enlarged versions.

The lightbox can be closed by:

- Clicking the close button.
- Clicking outside the displayed image.
- Pressing the Escape key.

The functionality was implemented in `js/gallery.js`.

### 5.3.3 Frequently Asked Questions (FAQ) Accordion

An interactive FAQ section was added to the About Us page.

The section provides answers to common customer questions about:

- Custom cake orders.
- Advance ordering requirements.
- Delivery arrangements.
- Specific cake designs.

JavaScript allows customers to expand and collapse questions to view the answers.

The functionality was implemented in `js/faq.js`.

### 5.3.4 Animations and Transitions

Animations and CSS transitions were introduced to improve the visual experience.

The enhancements include:

- Fade-in effects when selected content becomes visible.
- Scroll-based reveal animations.
- Hover effects on product cards.
- Smooth transitions on selected buttons and images.
- Reduced-motion support for visitors who prefer fewer animations.

The functionality was implemented in `js/animations.js`, together with the relevant CSS rules.

### 5.3.5 Responsive Hamburger Navigation

A hamburger navigation menu was introduced for mobile devices.

The menu uses a three-line icon that allows visitors to open and close the navigation links.

The five website pages remain accessible through the navigation menu.

Additional functionality includes:

- Opening and closing the mobile menu.
- Updating the menu's accessibility attributes.
- Closing the menu after a navigation link is selected.
- Maintaining the existing desktop navigation layout.

The functionality was implemented in `js/navigation.js`.

### 5.3.6 Search Engine Optimisation (SEO)

SEO improvements were introduced to help search engines understand the website's content.

The improvements include:

- Unique page titles.
- Meta descriptions for the individual pages.
- Improved H1 headings.
- Descriptive image alternative text.
- Meaningful image filenames.
- Clearer descriptions of the products and services.

### 5.3.7 Enquiry Form Validation

JavaScript and HTML validation were introduced to improve the accuracy of customer enquiries.

The enquiry form includes:

- Required full name.
- Required phone number.
- Required email address.
- Email format validation.
- Phone number pattern validation.
- Browser validation messages.
- A success and error feedback area.

These improvements help prevent incomplete or incorrectly formatted submissions.

### 5.3.8 AJAX Form Submission

The Fetch API was introduced to allow the enquiry form to communicate with an external form-handling service without refreshing the webpage.

The implementation includes:

- Preventing the default form submission.
- Validating customer information.
- Sending form information asynchronously.
- Displaying a submission progress message.
- Displaying a success message when the submission is accepted.
- Displaying an error message when submission fails.
- Resetting the form after a successful submission.

The functionality was implemented in `js/enquiry.js`.

# 9. Running the Website Locally

To run the website locally:

1. Download or clone the project repository.
2. Open the `MEL CAKES` folder in Microsoft Visual Studio Code.
3. Check that all HTML files, CSS files, JavaScript files and images are in their correct folders.
4. Open `INDEX.html` in a web browser.
5. Navigate through the website using the navigation menu.

The Visual Studio Code Live Server extension can also be used to run the website during development.
